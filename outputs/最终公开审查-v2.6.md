# 模型设置发布审查 · v2.6.0

2026-10-24。在 v2.5.0 已有经营复盘功能与验收基础上，增加网页模型设置。旧版 Release、ZIP 和 SHA256 保留，不覆盖。

## 新增能力

- 经营复盘与单表探索页面右上角统一“模型设置”入口；API 地址、模型 ID、密码框输入 Key，连接测试与立即保存。
- 默认只在当前服务进程内使用；明确勾选后才明文记住到本项目 `.env`，原子替换且保留无关设置。会话配置不会删除之前已记住的配置。
- 不回显 API Key、不写浏览器持久存储；保存或关闭弹窗后清空输入。响应 no-store；旧配置误填秘密到 URL/模型字段时也不回显。
- 更换服务地址须重新输入对应 Key；拒绝带账号/密码/查询参数的 URL，外部使用 HTTPS，本机回环可用 HTTP。连接测试不跟随重定向，避免转发 Key。
- 配置保存有同服务修订号，避免多窗口覆盖；测试单并发、无重试，最多 32 输出 token，测试不保存、不发送业务数据。
- 离线模式始终禁止配置写入及连接测试。普通模式保存立即生效；清除配置不修改外部网关或其他软件，并避免旧继承凭证在重启时重新启用。

新增 `tests/model-settings.test.cjs` 7 项交互逻辑：打开、空密码、保存后清空/状态更新、关闭清空、离线禁用、测试不保存、重复点击与网络失败恢复。这是 DOM 替身逻辑测试，不称为真实浏览器视觉验收。

完整回归为 293 项 Python 测试；JS 包含原草稿内部 7 条断言、原错误反馈 6 项、新设置逻辑 7 项和三个入口语法检查。固定 20 题连续两次运行，题集及数值期望未修改；题集 SHA256 仍为 `51b7eb3805f8d35c06279b69e622c1164df5a040910e326e6d184dbce1c4eb9f`。完整结果见 `outputs/closeout-acceptance-v2.6.0/evaluation.json` 及 JUnit。

## 边界与隐私

明文 `.env` 不是加密密钥托管，适合本人电脑上的单人工作台；不提供共享服务器多用户密钥隔离。页面会解释保存与数据传输含义，用户主动点击测试可能产生服务商费用；真实业务 AI 功能依旧会发送构造的分析上下文。

本轮不绕过此前浏览器工具的访问限制，没有新增真实浏览器视觉回归；历史截图保持原日期/版本标注，不冒充新设置页面。上游 TestClient 弃用提醒与生产/企业试用边界继续保留。此前发布版中的私人材料和实际凭证仍不进入本版本，发布前再次检查新源码、提交历史、ZIP 与嵌套 Excel。
