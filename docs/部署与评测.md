# 部署与评测 v2.5

已验证环境：Windows、Python 3.12.10、项目锁定依赖。前端原生 HTML/CSS/JS，无 npm 构建。服务仅监听 127.0.0.1，不提供账号或团队权限；不要直接暴露公网。以下 PowerShell 命令在解压后的项目根目录执行。

## 安装与启动

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/launch.ps1 -Offline
```

首次安装需要可用的 Python 3.12 和包下载网络。交付包不含 `.venv`、Python 安装器或 wheelhouse。完全断网时可直接看静态演示；交互版需预装依赖，或提前在匹配 Windows/Python 的联网机器下载完整 wheels 后运行：

```powershell
python -m pip download -r requirements.lock.txt --dest wheelhouse
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup.ps1 -Wheelhouse wheelhouse
```

离线安装流程支持本地 wheels 参数，但本轮未单独下载整套 wheels，不能声称已验证所有断网安装环境。安装失败返回非零退出码；完成依赖检查后才显示安装完成。已有项目继续用原目录，升级前先备份。

默认端口 8765。后台服务由独立隐藏进程承载，不依赖启动命令窗口继续存活。`work/service-端口.json` 记录实际 PID 与配置身份；停止时验证脚本绝对路径和唯一启动配置，拒绝关闭其他进程。不要手改运行记录。复制项目到新目录后应重新安装虚拟环境，不要复制 `.venv`。

```powershell
# 指定另一端口与数据目录；路径可含中文和空格
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/launch.ps1 -Offline -NoBrowser -Port 18765 -DataDir "$PWD\work\演示数据"
.venv\Scripts\python.exe scripts/service.py status --port 18765
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/stop.ps1 -Port 18765
```

普通启动省略 `-Offline`。默认普通数据 `data/`、离线数据 `demo-data/`；`-DataDir` 显式覆盖。启动前会检查并备份已有数据库，核查失败则中止。复用同一实例不会累积启动备份。相同端口不同数据或模式会拒绝启动；可换端口，但不要同时打开两个端口写同一数据目录。7863 是共享网关保留端口，禁止作为数策服务端口。

启动、停止数策均不启动、停止或修改共享模型网关。普通模式使用已经运行的 API；外部账户与网关由相应服务自行管理。公开版不包含本机网关管理脚本。

## 自动评测

每次选全新的输出目录，避免覆盖旧证据。自动评测不调用真实模型、不使用日常 data/，会在 work/ 下保留独立测试数据。

```powershell
.venv\Scripts\python.exe scripts/evaluate.py --out outputs/my-acceptance
```

评测顺序：Python 全套测试、JS 草稿测试与语法检查、隔离离线业务流程、备份恢复核查。任一步失败则退出码非零，证据保留在指定目录。JS 检查需要安装 Node.js；没有 Node 时明确失败，不伪造“跳过且通过”。Windows 启停验收会使用随机空闲端口，检查启动窗口退出后仍可请求、重复启动、模式冲突、停止身份保护、重启后报告保留。

仅生成一次离线材料也可单独执行：

```powershell
.venv\Scripts\python.exe scripts/offline_eval.py --out outputs/my-offline-demo
```

该评测用独立 SQL 核对 8 个门店/SKU 的原始交易金额，检查报告快照、三种证据导出及 Excel。它验证本工程样本的正确性，不代表未见业务数据上的准确率。模型故障测试使用替身注入 401/402/429/503、超时和格式错误；本轮不做真实 API 压测，避免消耗真实提供方资源。真实模型结果应另行标注模型、时间和测试范围。

## 打包与校验

```powershell
.venv\Scripts\python.exe scripts/package_project.py --dest outputs/my-delivery.zip
.venv\Scripts\python.exe scripts/verify_package.py outputs/my-delivery.zip
# 全新目录重新创建虚拟环境、安装依赖并验收；需安装网络或缓存
.venv\Scripts\python.exe scripts/package_smoke.py outputs/my-delivery.zip --to work/my-delivery-test --report outputs/my-delivery-test.json
```

打包只取显式源码目录、入口、手册和本版模拟演示/收尾证据。不包含日常数据库、原始用户数据、密钥、虚拟环境、工作日志或备份。ZIP 中的 `PACKAGE-MANIFEST.json` 提供逐文件 SHA256，校验器检查清单、CRC、重复/越界路径和禁止目录。相同目标 ZIP 已存在会报错；改名字保留上一版。

SHA256 清单检测损坏，不是签名或来源认证。取得 ZIP 后还应对照交付说明的整包 SHA256。解压到独立目录，先看用户手册，再安装/启动。静态 HTML 已检查无远程资源依赖；本轮浏览器工具的本地访问受到限制，未追加浏览器截图或声称完整视觉回归，原有 UI 截图仅代表历史检查。


## 固定题集及对比

完整 evaluate 命令会运行两次冻结的 20 题题集并生成前次对比。也可单独运行：

```powershell
.venv\Scripts\python.exe scripts/benchmark.py --out outputs/benchmark-first.json
.venv\Scripts\python.exe scripts/benchmark.py --out outputs/benchmark-next.json --previous outputs/benchmark-first.json
```

题目和期望值在 tests/benchmark-v1.json，以 .sha256 冻结；执行器也记录指纹，题集、执行器或模式不同时拒绝进行可比成绩计算。请勿为了通过率改题或放宽断言。新需求应创建新版本，并保留旧题和旧结果。

输出包含逐题耗时/总耗时、通过率、失败分类、时间、Git commit/dirty、模型 ID/参数、请求数和成本。本版为离线规则与确定性计算验收，模型字段为 null，API 成本为 0；不报告为真实模型成功率。没有 Git 时 commit 为 null，不能伪造提交。
